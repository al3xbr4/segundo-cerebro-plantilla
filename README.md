# Segundo cerebro

Bóveda de Obsidian para trabajar con Claude Code: `raw/` (bandeja de entrada), `wiki/` (conocimiento estructurado), `output/` (lo que produce Claude), `empresa/` (kit de un cerebro de IA para empresa) y `proyectos/` (grafos de código generados con Graphify).

- Para empezar, abre **`Inicio.md`**.
- Las reglas que sigue Claude están en **`CLAUDE.md`**.
- Para instalarlo en otro ordenador (Windows o Mac), sigue **[SETUP.md](SETUP.md)**.
