# Elegir camino: A, B o C

1. **¿La IA tiene que trabajar sobre tus sistemas (CRM, gestión, inventario), no solo responder y redactar?**
   Sí → **C** (y sigue con la 2 para saber si va sobre A o B). No → pasa a la 2.
2. **¿Necesitas alta/baja automática de usuarios, roles por grupo o auditoría?**
   Sí → **B**. No → pasa a la 3.
3. **¿Lo van a usar más de 150 personas?**
   Sí → **B**. No → **A**.

| Camino | Qué es | Coste orientativo (según la guía, oct. 2026) |

| C · A medida | Subagentes de Claude Code sobre tus sistemas, código en GitHub | GitHub Organizations gratis con repos privados |
